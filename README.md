# ⚙️ Business Process Intelligence & Operations Analytics

> **Portfolio of operational case studies focused on SLA compliance, cycle time bottleneck diagnosis, root cause auditing, and profit margin protection.**  
> Built with: **Google BigQuery (SQL)** • **Advanced Spreadsheets** • **Tableau Public** • **Process Root Cause Analysis**.
---

## 📌 Executive Overview
This repository functions as an operations and business process intelligence portfolio. Rather than presenting isolated academic exercises, each project simulates critical business challenges encountered in global operations, supply chain environments, and transaction processing hubs.

Every case study applies the **Google Data Analytics 6-Phase Framework** (*Ask, Prepare, Process, Analyze, Share, Act*) to deliver measurable operational outcomes: reducing cycle times, identifying root causes of process failure, and eliminating financial margin leaks.
---

## 🛠️ Core Competencies & Technical Stack

* **Data Modeling & Extraction (SQL / Google BigQuery):** Relational queries (`INNER`/`LEFT JOIN`), multi-condition segmentation (`CASE WHEN`), window functions, SLA elapsed time metrics (`TIMESTAMP_DIFF`), data mutation (`DML`), and query cost benchmarking.
* **Operational Auditing (Advanced Spreadsheets):** Anomaly and outlier auditing, dynamic multi-variable pivot matrices, text parsing (`REGEXEXTRACT`, `SPLIT`, `TRIM`), nested logic (`COUNTIF`, `VLOOKUP`/`XLOOKUP`), and automated workflow validation.
* **Business Intelligence & Reporting (Tableau Public / Looker Studio):** Executive dashboards, trend line modeling, root cause scatter plots, geographic mapping, and interactive action cross-filters.
* **Operational Frameworks:** SLA compliance monitoring, root cause auditing (5 Whys), cycle time reduction, inventory/logistics traceability, and unit economic margin protection.
